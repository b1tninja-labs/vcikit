# SAE J2534-1 — the clause map

The J2534 backend (`vcikit-j2534`) drives a registered SAE J2534 pass-through DLL for ISO 15765. Its
API — `PassThruOpen` / `Connect` / `StartMsgFilter` / `WriteMsgs` / `ReadMsgs` / `Disconnect` /
`Close`, the `PASSTHRU_MSG` struct, and the protocol / flag / filter / status constants — is SAE
J2534's. Every constant `vcikit` uses was **verified against SAE J2534 (2002)** through `primarysource`
(`sae:j2534-2002`, terms acknowledged 2026-11-22); none is from memory.

The 2002 edition already defines the ISO 15765 path (it is not a v04.04-only addition): §8.3.2 gives the
ISO 15765-4 data format, §8.4 the message flags, and §7.2 the `PassThru*` functions.

| Flow-control filter = mask `FF FF FF FF`, pattern = response id, flow = request id | — | §7.2.5; §9.2.2.1 Appendix B (filter usage) |

Two reader facts that shape `recv()` (§7.2.3): `PassThruReadMsgs` returns the **TxDone** confirmation
(RxStatus `TX_MSG_TYPE`) and the ISO 15765 **FirstFrame** indication (RxStatus `ISO15765_FIRST_FRAME`,
a zero-length message) as messages, in bus order, before the reassembled reply. `recv()` skips both and
returns the first frame carrying application data.

## Caveats

- **OCR.** `sae:j2534-2002` is a scanned PDF; its extracted text has OCR errors. Each value above is
  confirmed by its figure number and independently cross-checked against the recovered native
  pass-through `VCXPT32.dll` (session note `vcx-open-row-recovered-from-vcxpt32.md`). Re-read the clause
  before quoting wording verbatim; this crate cites clause + value, not OCR prose.
- **Edition.** The imported document is the 2002 edition. Later J2534-1 revisions (e.g. 2004 v04.04) keep
  these values; if a newer edition is imported, re-verify.

## ISO 22900-2 cross-reference

ISO 22900-2:2009 (`iso:22900-2@2009`) is the independent confirmation of the raw-mode CAN-id convention
(§9.2.6.3.6 request, §11.1.4.18.5 response) and maps the D-PDU API to SAE J2534-1 one-to-one (Annex A,
Table A.1). SAE J2534 is the pass-through source; ISO 22900-2 is the cross-reference. See
`docs/iso-map.md`.

## J2534-2 and RP1210a

No J2534-2 document is imported. RP1210a is named by ISO 22900-2 Annex A as a third raw-mode consumer
but is out of scope — this backend targets J2534-1 ISO 15765 only.
